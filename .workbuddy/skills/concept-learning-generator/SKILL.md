# Concept Learning Generator（概念学习资料生成器）

## 功能概述

给定任意一个概念名称，将概念拆解为结构化、可测验、可落地的 HTML 学习资料，帮助用户从"听说过"到"真正掌握"。

该 Skill 服务于中文学习者，产出的文档默认使用简体中文。

## 触发场景

当用户说这类话时使用本 Skill：

- "帮我生成一份 XX 概念的学习资料"
- "讲解一下 XX，做成资料给我"
- "为 XX 出一份分级测试题学习文档"
- "把这个概念整理成一份可自测的学习 HTML"
- "关于 XX，给我一套完整的学习笔记（含自测题）"

## 硬性约束（必须遵守）

1. **先查证、后输出，禁止编造**：在开始写任何正文前，必须先通过 `WebSearch`（必要时 `WebFetch` 打开权威原文）查阅资料。来源优先级参考：
   - 官方规范 / 标准文档（如 RFC、W3C、官方 GitHub、机构官网）
   - 权威百科与学术（Wikipedia/维基百科对应语言版、论文、教科书）
   - 知名机构/教材的公开资料
   - 使用交叉验证：同一事实至少有两个来源一致才落笔；不确定或存在争议的内容用"据资料，……"并标注来源，或明确说明存在不同说法。
2. **忠实引用来源**：参考资料链接模块必须列出**真实可访问**的链接，不得编造 URL。若确实无法确认链接有效，宁可只列来源名称 + 检索途径，也不虚构网址。
3. **匹配用户主题与语言**：输出的概念解释、示例、自测题需贴合用户所在知识域（工程/技术、科学、商业等），语言跟随用户。
4. **风格简洁**：产出自检时以"浅色单栏、减少颜色与图标、低认知负荷"为评审标准。

## 工作流程

### Step 1 — 澄清概念（如必要）

若用户只给了概念名称但含义有歧义（如同一缩写对应多义），可询问或用一句假设 + 括号注明来锁定语义。不要为明显无歧义的概念纠缠。

### Step 2 — 查阅权威来源（必须）

- 执行 `WebSearch`，查询「<概念名> 定义」「<概念名> 官方文档/规范」「<概念名> 原理/机制」「<概念名> 常见误区」等。
- 关键知识点至少查证 2 个来源。涉及定义、公式、机制、历史事实处重点核对。
- 把"已确认事实 + 其来源链接"记在草稿中，供后续正文与参考资料模块引用。

### Step 3 — 设计分级自测题

在生成正式文档前先规划题目（设计在前，避免正文不覆盖考点）：

- **基础题**（概念识记）：定义、关键术语、是否是……
- **进阶题**（机制理解）：为什么、机制如何运作、如何区分 A 与 B
- **应用题**（场景实操）：给一个具体场景/反例，让学习者判断或推演
- 每题提供答案与简要解析，注明题目来源是否来自权威资料。

### Step 4 — 生成 HTML

按下方「HTML 结构」生成**单个自包含 HTML 文件**（内联 CSS，不依赖外链，可直接打开）。

### Step 5 — 质检与交付

对照「质检清单」逐项检查后，将文件写入项目目录并用 `present_files` 呈现给用户预览。

## 输出：HTML 结构与样式规范

### 视觉规范（"浅色单栏"）

- 页面背景浅色（如 `#fafafa`），内容卡片白色（`#fff`），正文深灰近黑（如 `#1f2328`），次级文字灰（如 `#57606a`）。
- **单栏窄版式**：内容区最大宽度约 `720px`，左右居中，行距 1.6–1.8。
- **低认知负荷**：
  - 主色调为中性色 + 至多 1 个强调色（用于小标题/链接/标签），不堆砌彩色。
  - 少用 emoji 与图标；用清晰的文字层级、间距、少量分隔线组织信息。
  - 标题层级：h1 文档名 → h2 模块标题（带编号）→ h3 小节。
- 自测题为交互组件：选择题点击即时反馈对错并展示解析；应用题为可展开的参考解答。

### HTML 结构（8 个必需模块）

```text
<h1> 概念名：学习资料 </h1>
+ 文档元信息（概念名 / 领域 / 学习时长建议 / 更新日期 / 依据来源数）

1 学习目标 Learning Objectives       — 3-5 条可达成、可验证的目标（"学完你能……"）
2 核心问题 Essential Questions       — 2-4 个贯穿全文的驱动性问题
3 概念解释 Concept Explanation      — 一句话定义 + 通俗类比 + 权威定义引用 + 拆解
4 核心机制 Core Mechanism           — 分步骤/分模块讲解其如何运作（技术类给流程或结构）
5 应用场景 Applications             — 2-4 个真实/典型场景，每个含"场景→怎么用→为何有效"
6 易混淆问题 Confusions             — 与易混概念/常见误区对照（表格或并列表述）
7 分级自测题 Assessment             — 基础/进阶/应用三级，交互式选择题 + 应用解答
8 参考资料链接 References           — 按来源列出真实链接与来源类型
```

### 内联 JS 需求

- 选择题采用 `<button>` 选项，点击后高亮对错并显示"解析"段落（不跳页、不依赖外链库）。
- 页面可放一个简单的进度/总分提示（如答对 X/Y），帮助自测者掌握程度。

## 质检清单（交付前逐项过）

- [ ] 8 个模块齐全且顺序符合规范？
- [ ] 生成前查证过权威来源，正文无编造？存疑处已标注？
- [ ] 参考资料链接真实可访问（或已注明检索途径）？
- [ ] 自测题覆盖基础/进阶/应用三级，且有答案与解析？
- [ ] 视觉为浅色单栏、低认知负荷，无杂乱色彩与多余图标？
- [ ] 文件为自包含 HTML，可直接双击打开？

## 交付约定

- 文件名：建议 `概念名-学习资料.html`（英文可用 `concept-learning-<slug>.html`），写入项目目录（如 `D:\AI-homework\HuoYujia-learning-skill\` 下的合适位置或用户指定目录）。
- 用 `present_files` 打开预览。
- 完成后可询问是否需要：调整配色/难度、补充题目、导出 Word/PDF、或同步到仓库。
